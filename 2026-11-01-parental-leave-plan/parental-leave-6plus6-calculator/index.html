우리 육휴 설계도

6+6 부모함께 육아휴직 급여, 이렇게 계산해요

두 사람 모두 고용보험 근로자이고 자녀 생후 18개월 안에 각자 휴직을 시작하면, 첫 6개월 중 두 사람 모두 쓴 개월수까지 상한이 올라가요.

우리 부부 계획 짜기 (무료 · 가입 없음)

출산(예정)일과 두 사람 통상임금만 넣으면 추천 3가지 · 서버로 보내지 않아요

예시둘 다 월 500만원, 각 6개월

250 + 250 + 300 + 350 + 400 + 450 = 2,000만원 (한 사람)
두 사람 합계 4,000만원

예시둘 다 월 280만원, 6개월

250 + 250 + 280 + 280 + 280 + 280 = 1,620만원
(3개월째부터는 통상임금 280만원이 상한보다 작아 280만원)

예시함께 쓴 기간이 3개월 10일일 때

엄마 3개월 10일, 아빠 4개월(각 500만원) → 6+6은 짧은 쪽 3.333개월까지.
엄마: 250+250+300+350×(1/3) = 9,166,666원
아빠: 250+250+300+350×(1/3)+200×(2/3) = 10,500,000원 (연합뉴스 2026-05-06 보도 예시와 같음)

달 중간에 끝나는 기간을 나누는 정확한 방식은 확인 필요예요.

출처: 연합뉴스 팩트체크 2026-05-06 (공통 3개월 10일 예시) (2026-11-01 원문 확인)

자주 묻는 질문

6+6은 동시에 써야 하나요?

아니요. 같은 자녀에 대해 두 사람이 각각 생후 18개월 안에 시작하면 돼요. 동시에 쓰든 순서대로 쓰든 같아요(1350 상담 안내).

한쪽이 공무원이면 6+6이 되나요?

6+6은 고용보험 육아휴직급여 특례라 두 사람 모두 고용보험 근로자일 때 적용돼요. 공무원 수당은 별도 제도예요.

먼저 쉰 사람의 차액은 언제 받나요?

두 번째로 휴직한 사람이 급여를 신청할 때 첫 번째 사람 몫 차액도 함께 신청해요.

참고 추정치, 실제 지급·자격은 고용센터가 결정해요. 정확한 내용은 고용24(work24.go.kr) 또는 고객상담센터 1350에 확인하세요.
