“몇 명이야?” 대신 이름으로 확인하기

단체 겨울산행 사고의 공통 화근은 리더 판단 지연, 대열 분리, 통신 두절이에요 (월간산 사고사례). 갈림길마다 인원을 이름으로 확인하면 후미가 빠진 걸 바로 알 수 있어요.

앱의 인원 점검 모드

  1. 참가자 이름을 한 줄에 한 명씩 붙여 넣어요 (전화번호처럼 보이는 숫자는 자동 제거).
  2. 체크포인트: 출발 · 갈림길1 · 정상 · 하산 · 탑승.
  3. 이름을 누르면 확인 + 시각 기록, 다시 누르면 취소. 미확인 이름은 빨강.
  4. 상단에 “18/20 확인 · 미확인 2명”. 산행 당일 통과 마감이 지나면 빨간 배너.
  5. 새로고침해도 유지돼요 — 이 기기 브라우저에만 저장, 서버 전송 없음, 공유 링크에 포함 안 됨.

신고할 때 말할 순서: 산 이름·코스 → 가까운 산악위치표지판 번호 또는 국가지점번호(노란 표지판, 한글 2자 + 숫자 8자리) → 인원 → 상태 → 연락처. 번호판이 안 보이면 주소정보누리집 → 국가지점번호 → 나의 위치 지점번호. (대한민국 정책브리핑)

앱에서 우리 팀 반환 시각 계산하기
